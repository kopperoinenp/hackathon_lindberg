# Project overview

The Lindström account-manager demo prepares a customer review from a synthetic
workwear dataset. The manager can inspect calculated metrics and underlying data,
adjust the review through chat, and open or download a presentation for the meeting.

The approved interface has two tabs. The summary opens with a default review,
and detailed data supports checking the evidence behind it. The customer scope
and selected content carry into the browser presentation and editable PowerPoint.
